# Indian Bhabi — Black & Gold

A mobile-friendly Progressive Web App (PWA) starter.

## Included
- Responsive Black & Gold home page
- Bengali and English labels
- Installable PWA manifest and service worker

## Important
This is a front-end design starter only. Authentication, admin-only media uploads, private media storage, payment processing, and subscription enforcement are not implemented. Those require a secure backend. Do not put passwords, API keys, or private media in this public repository.

## Run
Open `index.html` in a browser for a preview, or deploy the repository with GitHub Pages.
